# My Student Portfolio

This is a personal student portfolio website created using HTML and CSS. 
The website presents my education, skills, projects, and contact information.

## Features

- Home section
- About Me section
- My Journey section
- Skills section
- Projects section
- Contact information
- Responsive and simple design
- Navigation bar for easy movement between sections/pages

## Technologies Used

- HTML5
- CSS3
